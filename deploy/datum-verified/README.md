# DATUMVerified for Umbrel

This folder is the Umbrel App Store package for **DATUMVerified**. It runs a settings page plus the Discord and Telegram DATUM Gateway verify bots on an Umbrel homeserver.

Official store packages live in [getumbrel/umbrel-apps](https://github.com/getumbrel/umbrel-apps). Community installs can add [yudikorsou/datumverified-umbrel-app-store](https://github.com/yudikorsou/datumverified-umbrel-app-store) from **App Store → Community App Stores**.
